# Внешний оригинальный Harness² - безопасный черновик в Second Brain

Этот необязательный маршрут использует результаты **неизменённого** [google-research/harness2](https://github.com/google-research/harness2), установленного отдельно по [Toolkit #421](https://github.com/MikeMoore1337/ai-development-toolkit/issues/421), закреплённого на `1cfe254e8d25b15f37048c3730134686abe60335`. Нет нового движка, форка, CLI-агента, платного API, изменений памяти или обхода проверки владельцем.

1. Оригинальный upstream должен **уже иметь настоящий** `summary.json` выполненного в разрешённой среде benchmark. Скрипт не создаёт такие данные и не запускает `harness2-demo`.
2. Скопировать только разрешённый внешний `summary.json` в локальный временный каталог вне приватного vault. Не передавать сырые агентные логи и секреты.
3. Выполнить из Second Brain `python scripts/harness2_import_note.py /absolute/path/to/summary.json`. Выводится Markdown на stdout, **не создаётся ни одного файла**.
4. В действующем интерфейсе Second Brain открыть «Добавить», вставить полученный Markdown, проверить предпросмотр и diff, затем явно подтвердить или отклонить сохранение. Никакой автоматической записи в vault не происходит.

Импорт принимает только известный формат `TaskResult.to_dict()` официального `harness2/core/schedule.py` (task_id/domain/k/status/modes/selections/base/errors/seed). Используются только безопасные метаданные и SHA256, не свободный текст из модельных выводов. Исходный статус **не доказывает** подлинность, эффективность, завершение оценки или безопасность. Если upstream меняет формат, скрипт должен отказать до отдельного контроля.

Работоспособность интеграции с оригинальным live upstream **не подтверждена** без реального файла. Синтетические тесты ниже подтверждают лишь разбор и запрет побочных эффектов.
