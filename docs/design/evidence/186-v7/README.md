# v7: открытые края и компактное завершение

Issue #186 / PR #187. Правка по скриншоту владельца, baseline `ae665fb`.

Удалены боковые линии page-filament и разделитель/тень под шапкой. Границы форм
и фокус остаются. У карточек «Память / Развитие» снят унаследованный min-height
270 px и уменьшены отступы. Старые декоративные круги заменены существующими
авторскими memory/growth-detail-192.webp: мягкий фон, а не новые функции.
Новых assets, зависимостей и внешних сервисов нет.

Цель эффекта — атмосферное завершение, без задержки пользовательских действий.

## Проверки и ограничения

- Build/TypeScript и **37 Vitest: PASS**.
- `node qa/open-edges.mjs`: 320/360/390/430/768/1024/1440/1920, отсутствие боковых
  линий/бордера шапки, overflow, компактные размеры, загруженные декоративные
  картинки без перехвата указателя, pause/offscreen/reduced: PASS.
- Два axe A/AA-аудита: **0 нарушений**. Desktop и mobile просмотрены в браузере;
  исправлены наследуемые отступы после первого прохода.
- CPU ×4, по 3 с на 1440/390: rAF median 16,7 мс, p95/max 16,8 мс.
  Это лабораторный замер, не гарантия кадровой частоты на физических устройствах.
- Backend и рабочие сценарии не менялись. Полный локальный Python suite и
  полный browser flow повторно не запускались: результаты предыдущего прохода
  приведены в [v6](../186-v6/README.md). Новые полные проверки выполняет PR CI.
- Физический телефон, реальная экранная клавиатура, screen reader и настоящее
  скрытие вкладки не проверены; hidden-ветка покрыта существующими unit-тестами.

Production React build на локальном синтетическом сервере; Chromium 151.0.7922.34.
Реальный vault, личные данные, LLM и платные операции не использованы.
