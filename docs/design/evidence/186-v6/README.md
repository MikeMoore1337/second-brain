# Проход v6: компактность, раскрываемые разделы и стекло

Issue #186 / PR #187, 9 сентября 2026. Предыдущая версия — `2eaeb41`.
Production React build, локальный синтетический DI-сервер на loopback, Chromium
151.0.7922.34. Реальные vault, LLM, микрофон, платные операции и env не использованы.

## Изменения

- Две кнопки паузы убраны. В меню остаётся один компактный switch «Анимация»;
  системный reduced-motion имеет приоритет.
- Добавление и поиск открыты. Семь остальных инструментов — native details/summary.
  При сворачивании React-компоненты остаются смонтированными: поля, результаты и
  незавершённые операции не сбрасываются. Все подтверждения сохранены.
- Меню раскрывает цель перед фокусом и прокруткой, включая повторный тот же hash.
  Прямой URL с hash раскрывает нужный раздел при загрузке.
- Иконка и заголовок идут рядом. Высокие декоративные вставки и повторное нижнее
  меню удалены; память и развитие оставлены кратким завершением.
- Стеклянные кромки, внутренние блики и глубина продолжают фиолетовую палитру.
  Blur ограничен навигацией. Формы плотные; меню читается поверх контента.
  Это CSS-интерпретация Liquid Glass, без новых assets, библиотек и системных API Apple.

а не гарантия постоянных 60 fps на реальных устройствах.

## Воспроизведение и границы

Синтетический сервер: `uv run python -m web.qa.serve`. В `web/`: `npm run build`,
`npm run test:run`, `npm run qa:design`, `node qa/compact-glass.mjs`,
`node qa/performance.mjs`, `node qa/scene-benchmark.mjs`.
Для артефактов этой версии установить `SB_QA_OUT=../.local/design-v6`; путь к
локальному Chromium задаётся `SB_QA_CHROMIUM`. Исходные версии отдельных v5 QA
со сценами остаются историческими и не входят в текущую команду `qa:design`.

Изменения ограничены React-представлением, его проверками и документацией.
API, Safe Write, доступ, same-origin и vault не менялись. **env change required: no**.
Merge и deploy не выполнялись.
