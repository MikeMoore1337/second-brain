# Проход v5 — логотип, выпадающие разделы и сквозное движение

Продолжение Issue #186 / PR #187 поверх b228271. Изменён production React GUI,
без нового приложения, API или функций обработки данных.

- Логотип — специально упрощённый фиолетовый мозг, также favicon. Название Second Brain
  остаётся читаемым текстом; мелкие буквы SB внутри рисунка намеренно не добавлены.
- «Разделы» открывают список возле кнопки на desktop и над нижней навигацией на mobile.
  Escape возвращает фокус, Tab проходит по обычным ссылкам, выбор переводит фокус в
  целевой раздел. Внешний клик и уход фокуса закрывают список.
- Три крупные композиции соединяют существующие инструменты. Добавлены свет по краям
  страницы, отдельные импульсы, появление иллюстраций, световые линии и заголовочные
  поверхности. Рабочий текст не двигается.
- Общая пауза управляет главной и всей страницей; доступна из меню. Невидимые композиции
  остановлены. При фокусе внутри рабочего блока его фоновый свет останавливается.
  Reduced-motion отключает декор и показывает причину в меню.
- На mobile меньше движущихся слоёв. Нижний навигационный блок получил нормальную
  ширину заголовка после визуального прохода.

## Проверки

- 320/360/390/430/768/1024/1440/1920 px: меню в границах viewport,
  без горизонтального overflow и controls меньше 44×44 px.
- Клавиатура: открытие через Enter, Tab к ссылкам, Escape с возвратом фокуса,
  переходы в добавление, хронологию, модель себя, поиск и память.
- Пауза: часы анимаций страницы и композиций не меняются 600 мс.
  Вне экрана композиция остановлена; reduced-motion — нет декоративных анимаций.
- axe WCAG A/AA: 0 найденных нарушений в открытом меню и проверенных состояниях
  композиций на desktop/mobile; общий браузерный suite также прошёл.
- Повторены текст/URL/голос → черновик, редактирование, preview, полный diff,
  отдельное подтверждение, успех; поиск → чтение; ошибки/loading и дополнительные
  разделы. До подтверждения 0 apply, после ровно 1.
- Build/typecheck и **36 Vitest tests** passed. Ruff format/check и mypy passed.
- Первый полный pytest: 1868 passed, один сбой при запуске TestClient в незатронутом
  тесте IPv6 host validation. Отдельный файл: 35 passed; повторный полный suite
  без изменений backend: **1869 passed, 10 skipped, 2 существующих warnings**, 74 с.
  Причина единичного сбоя не установлена; его не скрываем и не выдаём за исправление
  backend. Пропуски относятся к live-smoke gate, Linux bootstrap и Windows/POSIX
  symlink/FIFO ограничениям.

## Сопоставимые замеры

Chromium 151.0.7922.34, Windows, CPU ×4, 1440×1000, latency 100 мс,
download 200000 B/s, upload 100000 B/s, три холодных контекста,
2.5 с после load. Замеры выполнялись отдельно от тестов.
Baseline — сохранённый замер предыдущего b228271 в том же окружении и условиях.

| Показатель | b228271 | v5 |
| --- | ---: | ---: |
| FCP, медиана | 3652 мс | 3760 мс |
| LCP, медиана | 3984 мс | 4076 мс |
| Resource transferSize | 669333 байта | 709378 байт |
| JS / gzip | 413.60 / 122.78 КБ | 418.78 / 124.13 КБ |
| CSS / gzip | 97.26 / 18.17 КБ | 106.27 / 19.77 КБ |

FCP +108 мс (+3.0%), LCP +92 мс (+2.3%), transferred bytes +40 КБ (+6.0%).
Крупные иллюстрации lazy; браузер заранее загружает ближайшую к viewport.
Новых runtime-зависимостей, WebGL, внешних CDN, API-ключей нет.

Отдельные 4-секундные rAF-серии: главная и первая дополнительная композиция,
1440/390 px, CPU ×1/×4. Во всех сериях медиана 16.7 мс, p95 16.7–16.8 мс;
сопоставимая главная b228271 имела те же интервалы.
Это измерение данного headless-окружения, а не гарантия 60 fps на любом устройстве.

## Ограничения и происхождение

Физический телефон, настоящий IME, screen reader, реальная запись, LLM и микрофон
не проверялись. Hidden document покрыт unit-тестом; настоящее скрытие вкладки
на этом Windows-хосте по-прежнему не подтверждено.
Автоматический axe не означает полного сертификата WCAG.

Использован только synthetic loopback server; vault, API, same-origin и правила
сохранения не изменены. Данные и пауза не записываются в browser storage.
**env change required: no**. Merge/deploy не выполняются.
