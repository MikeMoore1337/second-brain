# Русский интерфейс v1

Статус: обязательное правило для рабочего веб-интерфейса React.

Основной пользовательский интерфейс, состояния, ошибки и текст для доступности
пишутся на русском языке. Английские слова не используются в тексте для
пользователя, если это не бренд или необходимый технический идентификатор.
Машиночитаемые значения API, имена маршрутов, коды ошибок и внутренние
идентификаторы остаются неизменными; на экране они показываются только с
русской подписью и только когда нужны для проверки или аудита.

`Код ошибки: SELF_MODEL_INVALID_REQUEST` или `Канонический UUID`.

## Обязательная проверка сайта

При каждом изменении сайта нужно проверить не только исходное состояние, но и
весь пользовательский путь: загрузку, успешный результат, ошибку, пустой
результат, отмену и подтверждение. Проверяются также `aria-label`, заполнители
(`placeholder`),
подписи полей и переносы на ширине 320, 360, 390 и 430px.

Пользовательский или внешний текст не переводится автоматически и не
подменяется локализацией: переводятся только продуктовые подписи и закрытые
внутренние коды. Для закрытых кодов используется русская подпись, а исходное
значение показывается лишь в техническом контексте, если оно нужно для аудита.

Минимальная проверка перед завершением:

Запрос ниже намеренно содержит исходные английские маркеры: это список для
поиска, а не видимый пользовательский текст.

```text
rg -n -i "Safe Write|Personal Memory|read-only|mapping|comparison|aggregate|vault|diff|editable|stated|observed|exact|review|lifecycle|manifest" web/src
npm run check
```

Найденное совпадение нужно классифицировать: код, имя API, бренд и другой
разрешённый технический идентификатор не переводятся; видимый пользовательский
текст переводится или получает русскую подпись.

## Представление ошибок

Сервер сохраняет стабильное поле `error.code`, но его `error.message` — это
короткое безопасное русское описание проблемы. В интерфейс не попадают
исключения, стек вызовов, сведения о провайдере, абсолютные пути и сырые сообщения
внутренних библиотек. Если внешний ответ не содержит понятного пользователю
русского сообщения, React показывает локальный русский запасной текст.

## Доступность и мобильные экраны

`web/index.html` объявляет `lang="ru"`. Кнопки, подписи, заполнители,
состояния загрузки, ошибки, пустого и успешного результата, а также
`aria-label` используют тот же глоссарий.
Русский текст должен переноситься на ширине 320, 360, 390 и 430px без
горизонтального переполнения; технические идентификаторы остаются вторичной
деталью.

Сборка React — единственный рабочий интерфейс. Старое статическое дерево
остаётся эталонным тестовым материалом и не является отдельной локализуемой
рабочей поверхностью.
