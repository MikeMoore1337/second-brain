# Проверка редизайна Second Brain — Issue #186 / PR #187

Доработка существующего PR: Onest, чёрно-фиолетовая палитра, независимые слои
декоративной сцены, согласованные рабочие поверхности и браузерная проверка.
Ниже перечислены подтверждённые результаты и границы проверки; автоматический
аудит не является сертификатом полного соответствия WCAG.

## Среда и данные

Windows, Node 24.19.0, Python 3.14.6, production Vite build из `web/`, FastAPI на
127.0.0.1:8137. Изолированный Playwright Chromium, установленная ревизия 1234,
без личного профиля. Реальные провайдеры, LLM, микрофон и second-brain-vault не
используются. `web/qa/serve.py` возвращает синтетические DI Draft/Save/Search/
Transcription и блокирует остальные API до обработчика. Дополнительные заполненные
состояния проверены контролируемыми JSON fixtures в Playwright.

Проверка Save подтверждает интерфейс, signed review/confirmation и количество
apply-запросов, а не реальную запись. Backend Safe Write покрывается suite проекта.
Шрифты, SVG и изображения загружаются только с собственного origin; данные и
пауза не сохраняются в browser storage. `env change required: no`.

## Сравнение с выбранным макетом

| Аспект | Реализация и осознанное отклонение |
| --- | --- |
| Композиция | Большой заголовок и действия слева, крупное ядро справа, низкий горизонт; без рекламной страницы перед работой |
| Цвет | Чёрный фон, несколько фиолетовых слоёв, лавандовый свет; зелёного нет, включая успех и diff |
| Типографика | Весь интерфейс Onest по последнему указанию владельца; антиква референса намеренно исключена |
| Глубина | Два отдельных локальных WebP, три SVG-орбиты, отдельные импульсы, фрагменты и частицы; исходный коллаж не подложен фоном |
| Mobile | Вертикальная композиция, два фрагмента и две орбиты, нижние быстрые действия; без нарисованного корпуса телефона |
| Смысл | Декор не является графом знаний; нет фиктивных отзывов, тарифов или неподдерживаемых функций |
| Работа | Спокойные поверхности чтения и редактирования; полный diff и отдельное подтверждение сохранены |

После первого просмотра исправлены чёрный прямоугольник слоя ядра, наложение
сцены на текст при 768 px, обрезание декоративных фрагментов на 320 px,
неправильное увеличение Markdown-заголовков и конфликт контраста кнопки сравнения.
Скриншоты пересняты после исправлений. Старый цельный WebP удалён.

## Функциональная и визуальная проверка

- 320/360/390/430/768/1024/1440/1920 px: нет горизонтального overflow;
  основные доступные controls не меньше 44×44 px.
- Desktop 1440×1000 и mobile 390×844: текст → черновик → редактирование →
  предпросмотр → полный diff → отдельное подтверждение → успех. До подтверждения
  0 apply-запросов, после — ровно 1. Редактирование инвалидирует старое подтверждение.
- Поиск → результат → чтение существующей заметки; пустой поиск; URL → черновик;
  синтетический WAV → текст → ручная правка → черновик: passed.
- Задержанный ответ → loading/disabled → русская ошибка 503 → восстановление
  редактирования: passed. Заполненные хронология, модель себя, прогноз,
  совет/сравнение, сбор контекста и диагностика проверены отдельно.
- Полная цепочка от skip-link до сохранения, поиска и фокуса чтения выполнена
  клавиатурой. Прокручиваемые заметки/diff фокусируемы; хронология использует li.
- axe WCAG 2 A/AA + 2.1 AA: 0 обнаруженных нарушений в начальном состоянии,
  черновике, diff, успехе и чтении на desktop/mobile, в заполненных дополнительных
  разделах и состоянии ошибки. Проверены фактические размеры targets и overflow.
- CDP CSS.getPlatformFontsForNode подтвердил custom Onest для латинского заголовка
  и кириллицы на обеих ширинах; скан computed styles не нашёл serif и зелёных оттенков.
- Пауза: часы непрерывных CSS-анимаций остаются неизменными; offscreen — остановка;
  reduced-motion на desktop/mobile — 0 декоративных CSS-анимаций, без параллакса.
  Проверены разные глубины pointer-планов и отсутствие параллакса на mobile.
- Короткий мобильный viewport с фокусом поля: нижняя панель убирается во время
  редактирования. Viewport meta запрашивает resizes-content; safe-area учтена.

PerformanceObserver, 2.5 с после load. Начальное состояние дополнительных функций
недоступно. Числа ниже — медианы, не field-data пользователей.

LCP +3.7%, FCP +12.6%, transferred bytes +14.2%. Основная цена — собственный
шрифт с кириллицей. Декоративные изображения стали меньше; runtime-зависимостей
не добавлено. Согласованность шрифта принята как осознанный компромисс загрузки.

requestAnimationFrame измерялся на живой сцене четырёхсекундными сериями при
CPU ×1/×4, отдельно от скриншотов. Desktop в этом headless окружении давал
интервалы 16.7–33.4 мс и отдельные 50 мс при ×4; mobile — преимущественно
16.7 мс. Удалён дорогой drop-shadow на больших SVG-орбитах. Это не доказательство
стабильных 60 fps: результат зависит от compositor/GPU и данного Windows-хоста.

## Ограничения

Физический телефон, настоящая экранная клавиатура, микрофон, screen reader и
реальная provider/write операция не проверялись. Клавиатура проверена изменением
высоты viewport, а не настоящим IME. INP полевых пользователей не измерялся.

visibilitychange и offscreen/resume покрыты отдельным unit-тестом; реальное
переключение/минимизация изолированного Chromium на этом хосте оставляло
`document.visibilityState=visible`. Поэтому остановка именно при настоящем
скрытии вкладки в браузере здесь **не подтверждена**; кодовая ветка проверена
детерминированным событием. Не выдаём это за успешно выполненный device-тест.

## Воспроизведение и артефакты

Из корня: `uv run python -m web.qa.serve`. В другом терминале, из `web/`:
`npm ci`, `npm run build`, `npx playwright install chromium`, `npm run qa:design`.
Для замеров отдельно: `npm run qa:performance`, без параллельных тяжёлых процессов.
`SB_QA_CHROMIUM` — необязательный путь к тестовому Chromium для сопоставления одной
ревизии; это переменная QA-процесса, не production-конфигурация.

[Скриншоты до/после и записи desktop/mobile](docs/design/evidence/186-v3/README.md)
включены в PR. Полные JSON-отчёты и расширенные screenshots — `.local/design-v3/`.
