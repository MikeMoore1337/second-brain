## Среда и граница доказательств

Production React bundle из `web/`, FastAPI на loopback. Исходный экран снят на 8136
без конфигурации vault (пустое состояние). Сценарии на 8137 используют DI fixtures
для Draft, Save, Search и Transcription; настоящие provider, microphone и vault
не используются. Фикстура Save возвращает синтетический diff и успех: это доказательство
UI-переходов, а не настоящей записи. Безопасность backend проверена обычным suite.
Скриншоты — браузерная эмуляция, не физический телефон.

## Сравнение с макетом и итерации

Открыты исходное изображение и captures реализации вместе. Макет — презентационный
коллаж 1672×941, поэтому сравнение композиционное: desktop-секция и первый телефон,
без сравнения внешних рамок и масштаба коллажа пиксель в пиксель.

1. Первый проход выявил конфликт CSS cascade: старый layout перетирал новую оболочку.
   Новая таблица подключена последней. Исправление проверено повторным capture.
2. На mobile свечение конкурировало с описанием. Верхняя часть сцены затемнена,
   текст и действия отделены от ядра. Сняты повторные desktop/mobile captures.
3. Рабочие поверхности получили спокойный тёмный материал, антикву в заголовках,
   читаемые поля, границы вторичных действий и сохранённые предупреждения.
4. При просмотре captures обнаружены промежуточные кадры изменения viewport.
   Рабочие разделы пересняты сериями при неизменной ширине; промежуточные кадры
   не используются как доказательство адаптивности.

## Браузерная функциональная проверка

- Текст → синтетический черновик → редактирование → предпросмотр → подготовка diff →
  отдельное подтверждение → сообщение успеха: пройдено.
- Изменение заголовка после подготовки убирает подтверждение: пройдено.
- URL `https://example.com/article` → синтетический черновик с provenance: пройдено,
  внешний HTTP-запрос не выполнялся.
- Синтетический WAV → подставной транскрипт → проверка текста → отдельное создание
  черновика: пройдено. Реальный микрофон и speech provider не проверялись.
- Поиск → результат → открыть → полный текст и фокус на `retrieved-note`: пройдено.
  Найден существующий дефект: React не распаковывал `{note}`. Исправлен с regression test.
- Пустой поиск: пройдено. Недоступность хронологии отображается по-русски.
- Навигация по всем текущим разделам и desktop/mobile captures: выполнено.
- Пауза: DOM `data-moving=true/running` → `false/paused`, восстановление движения: пройдено.
- Консоль: доступный журнал ошибок пуст.

## Адаптивность и доступность

`documentElement.scrollWidth <= innerWidth` на 320, 360, 390, 430, 768, 1024,
1440 и 1920 px в состоянии с открытой заметкой. Фокус чтения проверен в браузере.
Независимый reviewer нашёл несовпадение DOM/визуального порядка навигации — исправлено.
Существующие frontend/backend accessibility tests проходят; это не полный WCAG аудит.

Не проверены: физический телефон, настоящая экранная клавиатура/safe-area,
полный keyboard-only маршрут, 200% zoom, инструментальный контраст всех комбинаций.
Reduced-motion проверен unit-тестом и кодом CSS, но **не эмуляцией браузера**.
Скрытая вкладка и реальная реакция на изменение системной настройки не проверены.
